THE LAST SHOW - first-person carnival horror (Godot 4.3+, landscape, touch)
Find the knife. Stab the clown's 5 hearts (listen for the heartbeats). When the last one dies he kneels, crying.
Find him by the sound, kill him, take the key, open the main gate and escape.
Controls: left side = move, right side = look, RUN = sprint, LIGHT = flashlight, red button = interact.
Build the APK exactly like before (GitHub Actions workflow). Package name: com.microgames.lastshow
